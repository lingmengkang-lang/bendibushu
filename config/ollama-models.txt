# Ollama 推荐模型清单
# 说明：本文件只是清单，install.ps1 / start.ps1 不会自动拉取任何模型（尊重"只做工程产出"约定）。
#       实际可用模型以 Ollama 官方 library 页面为准：https://ollama.com/library
#       手动拉取示例：ollama pull qwen2.5:7b
#
# ---------- 推理模型（按显存选一即可，7B 约需 6~8GB 显存或纯 CPU 降速运行）----------
qwen2.5:7b        # 中文综合能力强，日常问答/办公首选
qwen2.5:14b       # 质量更高，显存需求约 10~12GB
llama3.1:8b       # 英文及通用任务均衡
deepseek-r1:7b    # 推理链显式输出，适合排障分析类任务
#
# ---------- 嵌入模型（可选，RAG 切换 provider=ollama 时才需要）----------
nomic-embed-text  # 英文为主；中文场景如 library 中不可用请更换为其他嵌入模型
#
# ---------- 硬件参考【⚠️以下为经验值，请以实际显存与 Ollama 运行日志为准】----------
# 8GB 显存  -> 7B Q4 量化
# 16GB 显存 -> 14B Q4 或 7B Q8
# 无 NVIDIA 显卡 -> 仅 CPU 推理，7B 可用但速度慢，建议先跑通再谈体验
