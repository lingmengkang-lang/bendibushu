# ---------- 推理模型（按显存+内存选一；CPU 卸载可突破显存限制，代价是速度）----------
qwen2.5:7b        # 最低门槛，24G 内存可 CPU 卸载跑；但 PLC 专业题偏弱，仅适合跑通流程
qwen2.5:14b       # 【推荐】24G 内存可舒适跑（部分层进 8G 显存）；PLC/工控准确性明显优于 7B

# ---------- 硬件与"速度换能力"参考【⚠️以下为经验值，请以实际显存/内存与运行日志为准】----------
# 8GB 显存        -> 7B Q4 量化
# 16GB 显存       -> 14B Q4 或 7B Q8
# 24GB 内存(本机) -> 14B 可舒适；32B 边缘（CPU 卸载，慢但能用）
# 不在意速度      -> 大模型靠 CPU 卸载到内存/硬盘，VRAM 非硬墙；上限取决于内存+硬盘
# 无 NVIDIA 显卡   -> 纯 CPU 推理，7B 可用但慢；14B+ 勉强，仅建议跑通流程
#
# ---------- PLC / 工控领域提示 ----------
# 该领域专业性强、易"幻觉"，建议：推理模型至少 14B；并把你们的
# 厂家手册 / 样本 / 现有程序（脱敏）喂进 RAG（见 docs/plc/rag_guide.md），
# 准确性远比单纯换更大模型来得实在。
