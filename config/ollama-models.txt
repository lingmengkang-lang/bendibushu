# Ollama 推荐模型清单（PLC / 工控离线助手）—— 原则：准确度优先，速度其次
# 说明：本文件是模型清单。两种拉取方式：
#       1) 自动（推荐）：.\scripts\setup_ollama.ps1   —— 会按本文件自动安装 Ollama 并拉取下列未注释模型
#          （GitHub Actions / CNB 的自托管节点流水线也调用同一脚本，见 docs\deploy\ollama_setup.md）
#          ⚠️ setup_ollama.ps1 会拉取下列全部未注释模型（合计数 GB~二十GB），请确保磁盘余量充足；
#             launcher.ps1（双击启动）只拉取第一个未注释项作为默认模型。
#       2) 手动：ollama pull qwen2.5:14b-instruct-q6_K
#       实际可用模型/量化 tag 以 Ollama 官方 library 页面为准：https://ollama.com/library
#
# ---------- 本机硬件实况（2026-10-25 实测：Lenovo Legion 5 16IRX9 / 83DG）----------
# 内存 16GB（2×8GB DDR5-5600 SO-DIMM 双通道；官方最大支持 64GB，必须成对升级）
# 显卡 RTX 4050 Laptop 6GB（6141 MiB）｜CPU i7-14650HX（16C/24T）
# 磁盘 C: 可用约 70GB、D: 可用约 299GB（建议 OLLAMA_MODELS 指向 D 盘，见 README 第四节）
# 选型原则：① 同尺寸上更高量化（Q4→Q6）= 速度换准确度；② 更大尺寸（32B/70B）必须先升级内存。
#
# ---------- 推理模型（CPU 卸载可突破显存限制，代价是速度）----------
# 【默认】首个未注释项即 launcher.ps1 拉取的默认模型
qwen2.5:14b-instruct-q6_K  # 默认：约 11.6GB，6G 显存卸载部分层 + 内存驻留；比 Q4_K_M 精度更高（速度换准确度）
deepseek-r1:14b           # 推理链显式输出，适合故障排查 / 逻辑分析类任务（约 9GB）
# qwen2.5:14b             # 回退：Q4_K_M 约 8.9GB，更快、精度略降；嫌慢可把默认改回本行
# qwen2.5:7b              # 回退：约 4.7GB，仅适合跑通流程；PLC 专业题偏弱
#
# ---------- 32B / 70B 档（需先升级内存，见下方升级路径；升级后取消注释即可）----------
# qwen2.5:32b-instruct-q4_K_M   # 约 19.8GB：内存升到 32GB 后的默认推荐，工控准确性明显再上一档
# qwen2.5:32b-instruct-q5_K_M   # 约 22.8GB：32GB 内存可试，接近占满
# deepseek-r1:32b              # 约 20GB：32B 推理链，排错类任务质量更高
# qwen2.5:72b-instruct-q4_K_M   # 约 40GB：需 64GB 内存；CPU 卸载，慢但质量顶格
#
# ---------- 嵌入模型（RAG 检索质量的关键；中文场景已切 bge-m3）----------
bge-m3                    # 中文/多语言嵌入，约 1.2GB，1024 维；中文检索明显优于英文向的 nomic-embed-text
# nomic-embed-text         # 回退：英文为主；换回需同步改 config/rag.config.json 的 embedding.ollama_model
#
# ---------- 硬件与"速度换能力"参考【⚠️以下为经验值，请以实际显存/内存与运行日志为准】----------
# 16GB 内存(本机现状) -> 14B Q6_K 为上限；32B 需先升级内存（见下方升级路径）
# 6GB 显存          -> 14B Q6 可卸载部分层；视觉 7B Q4 刚好驻留显存
# 32GB 内存(升级后)  -> 32B Q4_K_M 可舒适；视觉 32B Q4_K_M 可用
# 64GB 内存(升级后)  -> 32B Q6/Q8 或 72B Q4（CPU 卸载，慢但能用）；可多模型常驻
# 不在意速度         -> 大模型靠 CPU 卸载到内存/硬盘，VRAM 非硬墙；上限取决于内存+硬盘
# 无 NVIDIA 显卡     -> 纯 CPU 推理，7B 可用但慢；14B+ 勉强，仅建议跑通流程
#
# ---------- 内存升级路径（Lenovo 83DG：2×SO-DIMM，官方最大 64GB DDR5-5600，必须成对安装）----------
# 16GB -> 32GB：购 2×16GB DDR5-5600 SO-DIMM 替换现有 2×8GB；之后取消上方 32B 档注释即可
# 32GB -> 64GB：购 2×32GB DDR5-5600 SO-DIMM；之后可上 72B 档
# 操作要点：断电 → 释放静电 → 拆后盖 → 内存斜插入卡扣至两声 → 装回通电 → 进系统确认双通道与频率
# ⚠️ 拆机有风险（影响保修/卡扣断裂/静电击穿），不熟悉建议送联想服务站；升级前备份重要数据
#
