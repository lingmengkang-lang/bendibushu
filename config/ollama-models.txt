# Ollama 推荐模型清单（PLC / 工控离线助手）—— 原则：准确度优先，速度其次
# 说明：本文件是模型清单。两种拉取方式：
#       1) 自动（推荐）：.\scripts\setup_ollama.ps1   —— 会按本文件自动安装 Ollama 并拉取下列未注释模型
#          （GitHub Actions / CNB 的自托管节点流水线也调用同一脚本，见 docs\deploy\ollama_setup.md）
#          ⚠️ 内存护栏：模型所需最小内存（32B≈24GB / 72B≈48GB）超过本机物理内存时，
#             脚本会跳过拉取并提示（避免下完 20GB 却跑不动）；升级内存后重跑即可（幂等）。
#          ⚠️ setup_ollama.ps1 会拉取下列全部未注释模型（合计数 GB~四十GB），请确保磁盘余量充足；
#             launcher.ps1（双击启动）只拉取第一个未注释项作为默认模型。
#       2) 手动：ollama pull qwen2.5:32b-instruct-q4_K_M
#       实际可用模型/量化 tag 以 Ollama 官方 library 页面为准：https://ollama.com/library
#
# ---------- 本机硬件与目标配置 ----------
# 现状（2026-10-25 实测）：Lenovo Legion 5 16IRX9 / 83DG，16GB 内存（2×8GB DDR5-5600 SO-DIMM）
#   + RTX 4050 Laptop 6GB 显存 + i7-14650HX。已决策升级到 32GB（2×16GB 成对），
#   因此本清单按 32GB 目标预置 32B 默认档；内存升级完成前，启动脚本会自动跳过拉取并提示。
# 升级到 32GB 后：重跑 启动.bat 或 .\scripts\setup_ollama.ps1 即按本清单拉齐（幂等）。
# 磁盘：C: 可用约 70GB、D: 可用约 299GB（建议 OLLAMA_MODELS 指向 D 盘，见 README 第四节）。
#
# ---------- 推理模型（CPU 卸载可突破显存限制，代价是速度）----------
# 【默认】首个未注释项即 launcher.ps1 拉取的默认模型
qwen2.5:32b-instruct-q4_K_M  # 默认（32GB 内存档）：约 19.8GB，工控准确性比 14B 明显再上一档
deepseek-r1:32b             # 推理链显式输出，适合故障排查 / 逻辑分析类任务（约 20GB）
# qwen2.5:32b-instruct-q5_K_M  # 精度更高（约 22.8GB）：32GB 内存可试，接近占满；嫌紧就留在注释
# qwen2.5:32b-instruct-q6_K    # 约 26GB：建议 48GB+ 内存再开
# ---------- 16GB 回退档（内存未升级完成时，把首个未注释项改成下面这行）----------
# qwen2.5:14b-instruct-q6_K  # 约 11.6GB：16GB 内存当前上限（Q4→Q6，速度换准确度）
# qwen2.5:14b               # 约 8.9GB：Q4_K_M，更快、精度略降
# qwen2.5:7b                # 约 4.7GB：仅适合跑通流程；PLC 专业题偏弱
#
# ---------- 72B 档（需升级到 64GB 内存：2×32GB 成对）----------
# qwen2.5:72b-instruct-q4_K_M   # 约 40GB：质量顶格，CPU 卸载很慢；64GB 内存后再取消注释
#
# ---------- 嵌入模型（RAG 检索质量的关键；中文场景用 bge-m3）----------
bge-m3                    # 中文/多语言嵌入，约 1.2GB，1024 维；中文检索明显优于英文向的 nomic-embed-text
# nomic-embed-text         # 回退：英文为主；换回需同步改 config/rag.config.json 的 embedding.ollama_model
#
# ---------- 硬件与"速度换能力"参考【⚠️以下为经验值，请以实际显存/内存与运行日志为准】----------
# 16GB 内存 -> 14B Q6_K 为上限；32B 需先升级内存
# 32GB 内存(升级目标) -> 32B Q4_K_M 可跑（约 14GB 进内存，其余 CPU 卸载）；Q5_K_M 接近占满
# 64GB 内存 -> 32B Q6/Q8 或 72B Q4；可多模型常驻
# 6GB 显存 -> 32B 仅约 1/4 层进显存，其余靠 CPU：慢但能用（已按"速度换准确度"接受）
# 不在意速度 -> 大模型靠 CPU 卸载到内存/硬盘，VRAM 非硬墙；上限取决于内存+硬盘
#
# ---------- 内存升级路径（Lenovo 83DG：2×SO-DIMM，官方最大 64GB DDR5-5600，必须成对安装）----------
# 16GB -> 32GB：购 2×16GB DDR5-5600 SO-DIMM 替换现有 2×8GB；本清单默认档即为 32B，升级后重跑部署即用
# 32GB -> 64GB：购 2×32GB DDR5-5600 SO-DIMM；之后取消上方 72B 档注释
# 操作要点：断电 → 释放静电 → 拆后盖 → 内存斜插入卡扣至两声 → 装回通电 → 进系统确认双通道与频率
# ⚠️ 拆机有风险（影响保修/卡扣断裂/静电击穿），不熟悉建议送联想服务站；升级前备份重要数据
#
