qwen2.5vl:7b      # 【推荐】中文强、工控术语好，约 6GB；本机 6G 显存 + 24G 内存可 CPU 卸载跑（偏慢但可用）
# llava:7b        # 备选：更轻（约 4.7GB），但中文一般、工控术语略弱

# ---------- 硬件与“速度换能力”参考【⚠️经验值，以实际显存/内存与运行日志为准】----------
# 视觉模型比同等规模文本模型更吃显存/内存；6G 显存 + 24G 内存跑 7B 视觉模型需 CPU 卸载，首字较慢。
# 若图片解析很慢：换更小的视觉模型，或提高图片压缩率（前端已压到最长边 1024），或牺牲速度换准确度。
# 无 NVIDIA 显卡：纯 CPU 可跑 7B 视觉模型但很慢，仅建议跑通流程。
