## 1. 模型变大 ≠ 不出错（本审查最重要的判断）

- **事实**：32B 相比 14B/7B，工控类问题的幻觉率**下降但不归零**；且大模型"错得更自信"（表述更流畅、更少自我怀疑）是已知现象。
- **因此本轮准确度策略是三层兜底，缺一层都不行**：
  1. 模型层：32B + Q4_K_M 以上量化（够用就好，不为追 72B 牺牲可用性）；
  2. 检索层：bge-m3 中文嵌入，让你们的手册/参数表被**检索到并引用**（比换模型更实在的杠杆）；
  3. 规则层：10 条铁律 + 图片解析专用规则（看不清直说、推测标注"需现场核对"）。
- **给工程师的一句话**：可以把助手当"打了引用的初稿生成器"，**不能**因为"换成 32B 了"就免掉审核。
- 🟢 建议（不阻塞）：在 `docs/plc/SAFETY.md` 已有模板基础上，让工程师抽查 10~20 个真实问题，
  统计"引用来源是否正确/参数是否与手册一致"，用抽样合格率决定是否放宽审核强度。

## 2. 图片解析（看图）专项审查 —— 最需要工程师把关的新能力

图片解析的错误**比文本问答更危险**：文本幻觉尚可被"读起来像假的"识破，而"把铭牌 45kW 看成 48kW"
"把 0 看成 O"这类错误**看起来完全合理**，直接流入选型/调试就是事故。

### 2.1 四类场景的误读风险逐项评估

| 场景 | 主要误读风险 | 现有防护（VISION_PROMPT 规则） | 判定 |
|---|---|---|---|
| 电气/PLC 图纸、程序截图 | 符号按错标准解释；地址/寄存器看错；联锁关系漏读 | 逐字段精确读出 + 标注 0基/1基 + 符号按 IEC 60617 解释 + 联锁结构须说明 | 🟡 |
| 变频器/伺服/编码器 铭牌与参数面板 | **额定值看错（电压/电流/功率/防护等级）**；参数号与设定值错位 | 逐字段原样读出 + 易混字符（O/0、I/1、S/5、B/8、Z/2）显式提示核对 | 🔴 |
| HMI/组态画面、报警截图 | 报警代码与文本对应错；变量地址看错 | 读出变量名/地址/报警代码与文本 + 给排查顺序（标注为推测） | 🟡 |
| 通用 OCR | 长串字符（序列号/物料号）错字；换行顺序乱 | 尽量完整提取 + 保留换行顺序 | 🟢 |

### 2.2 🔴 必须由电气工程师核对的硬项（签名前）

1. **铭牌/参数面板场景**：请拿 3~5 块你们现场真实设备的铭牌与参数画面照片实测，
   核对"型号、额定电压/电流/功率、参数号-设定值"四类字段的**逐字正确率**。
   任一字段错一位（如 45kW→48kW、AC380→AC220）即判定该场景不可用，须回退到"仅提取文字、人工誊抄"模式。
2. **图纸符号集**：规则按 IEC 60617（GB/T 4728 等同）解释。**若你们现场在用厂内旧符号或前标准图纸**，
   请在知识库补入该厂符号说明文档，否则助手会用标准符号强行解释老符号——这是"自信地错"的典型入口。
3. **报警代码**：HMI/驱动器报警代码各家私有（且同厂不同系列不同）。助手给出的是"可能原因与排查顺序"，
   **必须按厂家手册核对后才可执行**；知识库里没有该厂家手册时，助手的报警解释只能当线索。

### 2.3 🟡 建议核对

- 易混字符规则（O/0、I/1、S/5、B/8、Z/2）是否符合你们设备铭牌的字符集（有些铭牌不用 O/I 区分）；
- 图纸场景要求助手"标出 0基/1基偏移"——请确认助手输出的偏移标注方式与贵司点表习惯一致；
- 翻拍屏幕的摩尔纹/反光会显著降低识别率，建议固定拍摄规范（正面、垂直、开闪、避反光）并写入 `docs/devices/`。

## 3. 嵌入模型切换（bge-m3）的影响评估

- **变的是什么**：RAG 嵌入从 Chroma 内置英文向 ONNX（384 维）切到 bge-m3（1024 维，中文强）。
  效果：中文手册/参数表的检索命中率与相关性提升 → 助手引用的"来源片段"更贴题 → **减少凭记忆编造**。
- **不变的是什么**：引用仍强制标注来源文件；答案仍只是"基于被引用文档的起草"。
- 🔴 **必须核对的硬项**：**助手引用得准不准，上限是知识库文档本身准不准**。
  bge-m3 会让"错的参数"也被更准地检索出来。请电气工程师确认导入知识库的手册/样本：
  ① 版本对应现场设备；② 参数表未经道听途说转抄；③ 脱敏充分（见 `docs/plc/rag_guide.md` 第五节）。
- ⚠️ 运维提醒（非电气问题但影响可用）：切嵌入后向量维度变化，**必须 `clear` 后重新 `add-all` 重建**，
  否则检索直接报维度错误（已写入 `docs/plc/rag_guide.md` 第 4.1 节）。

## 4. 档位与护栏的正确性影响（简要）

- 32B 在 6GB 显存上约 1/4 层进显存、其余 CPU 卸载：**只影响速度，不影响输出语义**；
- 内存护栏（RAM < 24GB 跳过 32B 拉取）防止"下完 20GB 却跑不动"——**纯运维保护，与输出质量无关**；
- 16GB 回退档（14B Q6_K）与 32B 目标档共用同一套提示词与红线，**降档不降安全标准**。
- 🟢 结论：本轮档位调整不引入任何新的"误导现场"路径。
