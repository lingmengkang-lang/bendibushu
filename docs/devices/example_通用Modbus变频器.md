## 2. 通信能力
- 支持协议：Modbus RTU（485）/ Modbus TCP
- 通信参数（示例）：RTU 19200/8/N/1，站号 1；TCP 端口 502
- 接线端子：RS-485 A/B（注意与 A/B 反接会不通）
- 通信限制：单次连续读最多 16 个寄存器；写入间隔建议 ≥ 100ms

## 4. 常用操作方法
- 上电调试：先设电机参数（功率/极数/额定电流）→ 自学习（可选）→ 低速点动验证方向
- 参数设置：面板 / 上位机软件 / 通信写入三种；**通信写入后是否掉电保持需确认**
- 点动 / 正反转：通过命令字位操作，先确认机械允许
- 恢复出厂：有专门参数，执行后所有设置丢失，执行前先导出参数备份

## 5. 上位机接入
- 推荐通信：Modbus TCP（以太网）优先，稳定且可多主站
- 推荐库：C# `NModbus`；Python `pymodbus`
- 读写示例（Python，⚠️ API 随版本变化）：

```python
# ⚠️ pymodbus v3+ 为 ModbusTcpClient，参数形式与 v2 不同，以你装的版本为准
from pymodbus.client import ModbusTcpClient

c = ModbusTcpClient("192.168.x.x", port=502)
if c.connect():
    # 读输出频率/电流/故障码（示例：起始 40002，读 3 个）
    rr = c.read_holding_registers(1, 3, slave=1)
    if not rr.isError():
        out_hz = rr.registers[0] * 0.1
        out_a  = rr.registers[1] * 0.1
        fault = rr.registers[2]
    c.close()
```

- 注意事项：
  - 写频率给定前先确认设备处于停止状态（有的型号运行中写入无效或报故障）
  - 批量读注意"单次最多 N 个寄存器"限制，超了要分批
  - 通信超时要设合理值（建议 500ms~1s），并做重试上限，避免死循环刷

## 6. 故障代码表（示例）

| 代码 | 含义 | 可能原因 | 处理方式 |
|---|---|---|---|
| 16 | 过流 | 负载卡死、加速时间过短 | 检查机械；加大加减速时间 |
| 25 | 过压 | 减速过快、制动电阻未接 | 延长减速时间；检查制动单元 |
| 30 | 欠压 | 输入电压低、瞬间掉电 | 检查电源与接线 |
| 39 | 过热 | 风机停转、环境温度高 | 清灰；改善通风 |

> 真实故障码务必以手册为准；不同批次固件可能有差异。

## 7. 接线与电气注意
- 电源：按铭牌，注意三相/单相不要接错
- 控制回路：启停/使能尽量用硬接线保证可靠
- 接地 / 屏蔽：485 用屏蔽双绞线，单端接地，远离动力线
- **必须硬接线的保护：急停、上下限位**——软件里的"停止"只是通信指令，不能替代
