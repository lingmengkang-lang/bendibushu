# 工控设备调试与组态指引（变频器 / 伺服 / 触摸屏 / 编码器 / 组态软件 / 上位机）

本文件给出常见工控设备的调试要点与检查清单。所有操作须在 `SAFETY.md` 前提下、
由合格工程师执行；AI 可辅助起草方案，但**不能替代现场调试经验**。

## 一、变频器(VFD)调试 检查清单
- [ ] 核对电机铭牌：功率、电压、电流、额定频率，必须与变频器匹配（Pxxx 类参数）；
- [ ] 设置加/减速时间：按负载惯量，过短易过流/过压；
- [ ] 载波频率：默认即可，EMC 敏感场合可调低（注意发热）；
- [ ] 控制方式：端子 / 模拟量 / Modbus 给定；多段速由端子组合或通信写入；
- [ ] 点动(JOG) 先低速验证转向与机械；
- [ ] 保护：过载、过压、欠压、短路、接地保护确认；
- [ ] 上电前断电验电，确认主回路接线（R/S/T、U/V/W）无误。

## 二、伺服电机调试 检查清单
- [ ] 接线：动力 U/V/W、编码器线、使能、急停链；屏蔽接地；
- [ ] 上电先不使能，确认驱动器无报警；
- [ ] 参数：电机型号自整定（惯量辨识）做一次；
- [ ] 原点回归：选回零方式（限位/寻零/就近），确认到位；
- [ ] 三环增益：先位置环，再速度环，最后电流环；出现抖振/噪音回调；
- [ ] 电子齿轮比：按机械传动比与编码器分辨率计算；
- [ ] 限位与软限位：必须设置，避免撞机；
- [ ] JOG 低速验证运动方向与行程。

## 三、触摸屏(HMI)组态 检查清单
- [ ] 通信口/协议：与 PLC 一致（如 Siemens S7、Modbus RTU/TCP、MC Protocol）；
- [ ] 变量/标签：地址、类型、读写权限与 PLC 对应；
- [ ] 画面：启停、状态、报警、趋势；
- [ ] 报警：触发条件、确认、历史；
- [ ] 离线模拟验证后再下装。

## 四、编码器使用 要点
- **增量式**：A/B 相正交计数 + Z 零位；接 PLC 高速计数器或运动轴；
- **绝对式**：SSI / EnDat / BiSS 等，上电读位置，省去回零（首用校准）；
- **抗干扰**：双绞线、屏蔽单端接地、远离动力线；
- AI 可辅助：型号选型、接线说明、与 HSC/运动指令配合逻辑。

## 五、组态软件(HMI / SCADA)组态 检查清单
适用于 组态王、MCGS、台达 DIAEntegro、WinCC、力控、威纶通 等：
- [ ] **变量点表**：I/O 变量与内存变量逐一列出（名 / 地址 / 数据类型 / 读写权限）；
- [ ] 地址映射核对：Modbus 保持寄存器 ↔ PLC 数据区（如 D0、DB 块）换算，**逐点核对**；
- [ ] 设备/通信驱动：站号、波特率、IP、端口与下位机一致；
- [ ] 通信超时/重试、断线处理策略配置；
- [ ] 画面：启停、状态、数据输入、报警列表、实时/历史趋势；
- [ ] 报警：触发条件、确认机制、历史存储；
- [ ] 脚本/命令语言：复杂逻辑先在离线/仿真环境跑通；
- [ ] **离线模拟（或组态软件自带模拟）通过后再下装/下发**。

## 六、上位机通信 检查清单（C# / Python / LabVIEW 等 PC 软件）
- [ ] 协议与参数：Modbus TCP/RTU、OPC UA、S7、MC 等，IP/端口/站号/波特率正确；
- [ ] **异常/超时处理**：连接失败、读写超时、CRC/校验错要有重试与降级，不卡死；
- [ ] 轮询频率：控制采样周期，避免高频轮询打扰设备（尤其串口 RTU）；
- [ ] **写入校验**：写寄存器前做边界/合法性检查，关键参数写入需二次确认；
- [ ] 数据字典：寄存器分配表（地址 ↔ 变量名 ↔ 含义）与下位机一致；
- [ ] **安全红线**：软件互锁/急停**不能替代硬接线急停**；关键安全在 PLC/硬件层实现；
- [ ] 日志与权限：操作留痕，必要时加账号/权限控制。

> 这些清单是经验性提示，具体参数与步骤**以设备/软件手册为准**；调试务必遵守 `SAFETY.md` 红线。
