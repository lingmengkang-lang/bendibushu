# 知识库示例文档（RAG 参考样板）

> 实际使用时请替换为你自己的手册/样本内容，并注意**脱敏**。

## 示例：汇川 IS620P 伺服 —— Modbus 参数配置要点（节选）

- **通信**：RS485，Modbus RTU，默认波特率 19200，站号 1；
- **电子齿轮比**：通过参数 `PA-52`（分子）/ `PA-53`（分母）设置；
  例：机械 1 圈 = 10000 脉冲，则设分子=10000、分母=电机编码器分辨率对应值；
- **控制模式**：参数切换为位置模式（脉冲指令）或速度模式；
- **报警**：常见 Err-21（过载）、Err-10（过速）—— 先查机械卡滞与增益。

## 示例：西门子 S7-1200 —— 高速计数器(HSC) 配置思路

- 在 TIA Portal 设备配置中启用 HSC，选择计数模式（单相/双相/A/B 相）；
- 设定计数初值与上下限，绑定中断 OB 处理计满/比较事件；
- ST 中通过 `CTRL_HSC` 指令装载当前值与参数。

## 示例：变频电源(VFD) —— 关键参数

- 电机额定功率/电压/电流必须与铭牌一致（Pxxx 系列参数）；
- 加速/减速时间根据负载惯量设定，过短易报过流；
- 多段速可由端子组合或 Modbus 写入频率给定。
