# 图片解析（看图）能力指南

本地离线工控助手支持**上传图片 → 视觉模型解析 → 结合工控知识与安全红线作答**。
全程本地运行，数据不出本机；⚠️ 解析结果仅作**起草参考**，须经工程师核对原件 + 仿真验证后方可采用。

## 1. 怎么用（Web 界面）

1. 启动后浏览器打开 `http://127.0.0.1:8500`。
2. 点输入框左侧 **📎 图片**，或**把图片直接拖进输入框**，选择图片（png/jpg 等）。
3. 可附带一句话说明你想问什么（例如："读出这个变频器的参数"），也可只发图。
4. 点发送 —— 有图时自动走**视觉模型**（`config/ollama-vision-model.txt` 指定，默认 `qwen2.5vl:32b-q4_K_M`，24GB 部署机档），无图时走文本模型。
5. 前端会把图片**压缩到最长边 1024** 再上传，降低载荷、加快推理。

> 顶部状态栏会显示 `视觉✓ <模型>` 或 `视觉✗ 未拉取`。若未拉取，先执行 `ollama pull qwen2.5vl:32b-q4_K_M`（首次需联网）。
> 若部署机（24GB）没有独显、跑 32B 太吃力：把 `config/ollama-vision-model.txt` 首个未注释项改成
> `qwen2.5vl:7b-q4_K_M`（约 6GB）即可；16GB 开发/验证机上启动脚本会自动跳过 32B 拉取并提示。

## 2. 四类支持的场景

| 场景 | 上传什么 | 助手会做什么 |
|---|---|---|
| **电气/PLC 图纸、程序截图** | 原理图、接线图、梯形图/指令表/ST 程序截图 | 说明图/程序结构与联锁逻辑，标出地址/寄存器及其 **0基/1基偏移** |
| **变频器/伺服/编码器 铭牌与参数面板** | 设备铭牌、参数设定画面照片 | 列出型号、额定电压/电流/功率、参数号与设定值、端子定义 |
| **HMI/组态画面、报警截图** | 触摸屏画面、组态运行画面、报警/错误信息截图 | 读出变量名/地址、报警代码与文本，给出可能原因与排查顺序 |
| **通用 OCR** | 手册页、标签、说明文字照片 | 尽量完整提取为可复制文本，保留换行与顺序 |

## 3. 准确度是怎么保的（重要）

图片解析最容易"看错还硬答"。本工程在系统提示词里固化了一组**图片解析专用规则**，核心是"看得清的才说"：

- **识别边界**：严格区分「图中确实可见」与「推测/常识」；推测必须标注"（推测，需现场核对）"。
- **逐字段精确**：型号/参数号/额定值/端子号/地址/单位逐个原样读出；易混字符（O/0、I/1、S/5、B/8、Z/2）结合上下文判断并提示核对。
- **不认识的直说**：符号、字段看不清或不认识就明说，不瞎猜（图纸符号按 IEC 60617 / 行业惯例解释）。
- **叠加知识库（RAG）**：若你输入了文字问题，会同时检索知识库（厂家手册/样本）作为上下文，进一步提高针对性与准确度。
- **模型选型**：`qwen2.5vl:32b-q4_K_M` 图纸/OCR 精度显著强于 7B（24GB 部署机档）；对准确度要求极高时，可在知识库补入该设备手册后再问。

> 提升准确度的最有效手段：把对应厂家手册/样本（脱敏）喂进 RAG（见 `rag_guide.md`），并优先用清晰、正面、光线均匀、无遮挡的原图；避免翻拍屏幕的摩尔纹、过暗/过曝。

## 4. 模型与硬件

- 默认视觉模型 `qwen2.5vl:32b-q4_K_M`（约 20GB，24GB 部署机档），在 `config/ollama-vision-model.txt` 中可改。
- **部署机（24GB）**：32B 视觉模型约 20GB，是及格线——该机有独显（≥4GB）时舒适，纯核显接近上限、偏慢；能跑但首字较慢，换来图纸/OCR 精度显著提升。
- **回退档**：24GB 机无独显或跑不动时改用 `qwen2.5vl:7b-q4_K_M`（约 6GB）；启动脚本内存不足时会自动跳过 32B 拉取并提示，不会卡死。
- 拉取：首次 `ollama pull qwen2.5vl:32b-q4_K_M`；`launcher.ps1` 首次部署会 best-effort 自动拉。

## 5. 降级与排障

- **Ollama 未运行**：提示先安装并启动 Ollama（见 README 使用指南）。
- **视觉模型未拉取**：提示 `ollama pull qwen2.5vl:32b-q4_K_M`，拉完即可用。
- **内存不足被护栏跳过**：在 24GB 部署机上一般不会触发；若触发，按提示加内存，或临时改 `config/ollama-vision-model.txt` 首个未注释项为 `qwen2.5vl:7b-q4_K_M`。
- **想不装视觉模型**：图片解析不可用，但文本问答/RAG 仍正常（优雅降级，不影响其它功能）。
- **解析很慢**：换更小视觉模型 / 提高前端压缩率 / 牺牲速度换准确度。

## 6. 安全红线（与全文一致）

图片中的参数、图纸、程序仅作**起草参考**；正式采用前必须由合格工程师**核对原件 + 仿真验证**；
涉及联锁/急停/限位/过载等安全回路，务必以**硬接线/安全继电器**兜底，软件互锁不能替代硬急停；
绝不能仅凭图片识别结果直接下装到现场设备。
