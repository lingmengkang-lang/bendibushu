# PLC / 工控自动化 · 安全红线

> 本助手生成的 PLC、伺服、变频器、HMI、组态软件、上位机相关代码与方案**仅供起草、教学与查错参考**，
> **绝不能直接下装到现场设备**。工控系统直接控制真实机器，错误可能导致
> 设备损坏、停产、甚至人身伤害。请务必遵守以下红线。

## 一、必须做的（部署前）
1. **合格工程师审核**：AI 输出必须经持有相应资质、熟悉该设备的自动化工程师逐行审查。
2. **仿真验证优先**：先在 PLC 仿真器（如西门子 PLCSIM、三菱 GX Simulator、欧姆龙等）
   或离线逻辑测试环境中充分验证，确认逻辑、联锁、急停、边界条件全部正确。
3. **先小批/单机试**：现场首次下装只针对非关键或隔离回路，观察后再逐步扩大。
4. **备份先行**：任何改动前备份当前可用工程与参数；保留上一个可回滚版本。
5. **HMI / 组态软件离线模拟**：画面下装前用厂家模拟器（如 WinCC 模拟、GT Simulator、EBPro 模拟、MCGS 模拟运行）
   逐项核对变量映射、通信参数与报警逻辑，避免下装后显示错乱或控制误动作。
6. **上位机离线验证**：PC 软件先在实验室/仿真 PLC 或回环环境跑通通信与逻辑，再连真实设备。

## 二、永远不要做的
- ❌ 不审核、不仿真，直接把 AI 代码下装到产线/设备。
- ❌ 跳过联锁（Interlock）、急停（EStop）、限位、过载保护等安全回路。
- ❌ 把真实工艺配方、账号、网络拓扑、涉密图纸等敏感信息喂给联网服务（本工程默认离线，
  若开启云端混合路由，严禁外泄）。
- ❌ 照搬示例中的 PID 参数（Kp/Ki/Kd）、延时、阈值、电子齿轮比——必须结合实际对象现场整定。
- ❌ 用上位机/组态软件的软件互锁**替代**硬接线急停或安全继电器。

## 三、高风险环节特别提示
- **伺服 / 驱动器**：原点回归、行程限位、力矩限制、加减速时间错误可能导致机械撞击；
  上电前确认接线与使能逻辑。
- **变频电源 / VFD**：载波频率、加减速、电机额定参数错配会烧毁电机或变频器；
  确认电机铭牌与变频器功率匹配。
- **触摸屏（HMI）/ 组态软件**：画面变量**地址/类型/读写权限填错**会导致误显示甚至误动作；
  通信参数（站号、波特率、IP、端口）错会导致"连不上"或读写错位；
  **务必离线模拟 + 核对变量映射表**；脚本/命令语言逻辑错也会误动作。
- **上位机程序**：写寄存器**不做边界/合法性校验**会写入错误值触发设备误动作；
  无超时/异常处理会在设备掉线时卡死或雪崩；**轮询频率过高**会打扰串口/设备；
  **软件层急停/互锁不能替代硬接线安全回路**。
- **编码器**：A/B/Z **接线极性/相序错误**会导致计数反向、方向判错；Z 零位或绝对式零点
  校准错误会导致定位偏差；屏蔽接地不良会引入干扰使计数跳变。**上电前核对 A/B/Z 与电源，
  单端/差分匹配正确**。
- **急停与安全**：急停必须硬接线、常闭、独立于 PLC 程序；不可仅靠软件互锁。

## 四、本工程的责任边界
- 本仓库是**辅助工具**，不是自动编程机器；使用者对最终下装到设备的程序负全责。
- 对安全相关（SIL/PLd）功能，请遵循相应标准（IEC 62061 / ISO 13849）并由专业安全评估确认。

> 一句话：**AI 起草 → 工程师审核 → 仿真验证 → 隔离试车 → 再投产。**
