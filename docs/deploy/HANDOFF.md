## 1. 项目是什么

**本地离线工控 AI 助手**：跑在本机（不上云）的问答 + 知识库（RAG）系统，面向
PLC 编程 / 变频器调试 / 伺服调试 / 触摸屏(HMI) / 编码器 / 自动控制软件写程序六大工控场景。
技术栈：Ollama（本地大模型引擎）+ Chroma（本地向量库）+ 纯标准库 Web 界面（端口 8500）。
**唯一需要联网的一次**：首次安装 Ollama + 拉取模型（约 60GB）；之后完全离线，数据不出本机。

⚠️ 安全定位：助手输出仅作**起草参考**，正式采用前必须由合格工程师核对原件 + 仿真验证；
涉及联锁/急停/限位/过载等安全回路，必须以硬接线/安全继电器兜底。详见 `docs/plc/SAFETY.md`。

## 6. 在这台电脑上从零部署（按顺序执行）

### 步骤 0：准备

1. 确认磁盘：放模型的盘余量 ≥100GB（默认模型落 `%USERPROFILE%\.ollama\models`，即 C 盘用户目录）。
   若大余量盘不是 C 盘，**先设环境变量再启动**（重启终端后生效）：
   ```powershell
   setx OLLAMA_MODELS "D:\ollama-models"   # 改成你实际的大余量盘路径
   ```
2. 获取仓库（第 2 节方式 A 或 B）。

### 步骤 1：首次启动（全程需联网，约 1-2 小时，主要是下载 60GB 模型）

进入仓库目录，**双击 `启动.bat`**（或以管理员身份运行一次，装 Ollama 需要 UAC 授权）。
脚本会自动依序完成：

1. 检测 Python 3.10+（没有会引导安装）
2. 创建 venv + 安装依赖（含 `ollama` Python 包，bge-m3 嵌入需要）
3. 检测/安装 Ollama 引擎
4. 拉取文本默认模型 → 视觉模型 → 排错模型 → bge-m3（护栏放行即拉，已拉的跳过，**幂等**，中断了重跑即可）
5. 导入知识库（best-effort）
6. 启动 Ollama 服务 + Web 界面，浏览器自动打开 `http://127.0.0.1:8500`

> 若脚本装 Ollama 失败（UAC/网络）：去 https://ollama.com/download 手动装，然后重跑 `启动.bat`（幂等）。

### 步骤 2：验证真的跑起来了（重要——这是此前未实测的部分）

浏览器打开 `http://127.0.0.1:8500`，逐项确认：

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 顶部状态栏 | 显示 `模型✓ qwen2.5:32b-instruct-q4_K_M` 和 `视觉✓ qwen2.5vl:32b-q4_K_M`（不是 ✗） |
| 2 | 文本问答 | 问"电机星三角启动的 ST 程序怎么写"，能给出结构合理的起草（含联锁/急停要点） |
| 3 | 图片解析 | 点输入框 📎 上传一张变频器铭牌照片，能逐字段读出型号/额定值/参数号，看不清的会明说 |
| 4 | 速度观感 | 32B 首字可能等几秒~几十秒（CPU 卸载层数决定），属正常；能连续对话不卡死 |
| 5 | 离线验证 | 拔网线后重复 2/3，应完全正常 |

### 步骤 3：导入你们的资料（准确性的关键）

把厂家手册 / 样本 / 现有程序（**脱敏**）按品牌+设备类型放进：

```
data/knowledge_base/docs/
```

然后重建并导入向量库：

```powershell
.\venv\Scripts\python.exe scripts\rag_manager.py clear
.\venv\Scripts\python.exe scripts\rag_manager.py add-all
```

> ⚠️ **为什么必须 clear + add-all**：嵌入模型从英文向的 MiniLM 换成了中文向的 bge-m3，
> 向量维度 384 → 1024，新旧向量不兼容，混用会报错。首次部署本机是全新库，步骤 1 的 add-all 即可；
> 但**每次改嵌入模型/换机器迁数据，都必须先 clear 再 add-all**。

### 步骤 4：日常使用

- 启动：双击 `启动.bat`；停止：双击 `停止.bat`
- 之后每次开机只用 `启动.bat`，不再下载任何东西（完全离线可用）
- 更多能力（组态 TOP5 自动编程框架、品牌接入模板、上位机样例）见 `README.md` 第八节和 `docs/plc/` 目录

## 8. 已知限制与待办（诚实清单）

1. **8 项电气签字核对单**（`docs/review/model_upgrade_review.md` 第 6 节）尚未经真人工程师签认，
   特别是铭牌额定值逐字正确率、图纸符号集（IEC 60617 vs 厂内旧符号）、报警代码对厂家手册三项 🔴。
2. **模型变大 ≠ 不出错**：大模型幻觉更少但"错得更自信"，铭牌额定值看错（如 45kW→48kW）比文本幻觉更危险。
   准确性 = 模型 + 你们的资料（RAG）+ 10 条铁律三层兜底，缺一不可。
3. 首次拉取 60GB 期间不能中断 Ollama 进程；中断了重跑 `启动.bat` 即可续传。
4. 若后续想上更大档位（Q5_K_M / 72B），需先给本机加内存（双 SO-DIMM 必须成对，先确认官方最大容量），
   再取消 `config/ollama-models.txt` 对应行注释——一行切换。
