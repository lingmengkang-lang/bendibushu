# 组态王 KingView —— AI 自动编程能力

> 国产 SCADA 使用率第一，存量工程与教程最多。本文件说明**让本地助手自动产出组态王工件**的方法。
> 所有样例仅供起草，⚠️ 语法随版本（6.53 / 6.55 / 7.x）变化，以你所用版本手册为准。

## 一、核心概念速查

| 概念 | 说明 |
|---|---|
| **I/O 变量** | 与外部设备数据交换的变量，必须绑定"设备"中的寄存器 |
| **内存变量** | 内部计算用，不占设备通道 |
| **设备** | 设备窗口里配置的 PLC/仪表驱动（串口或以太网） |
| **命令语言** | 脚本，分：**数据改变**（变量变就执行）、**事件**（条件满足执行一次）、**定时**（按周期执行）、**热键**、**应用程序**、**画面**、**自定义函数** |
| **画面** | 用户窗口，放图元/控件/动画连接 |
| **报警 / 趋势** | 报警窗口 + 实时/历史趋势曲线 |
| **变量引用** | `\本站\变量名`；跨站点用 `\站点名\变量名`；系统变量如 `$Year/$Month/$Day/$Hour/$Minute/$Second` |

## 二、AI 能自动产出什么

- **变量点表**：变量名、变量类型（I/O/内存）、数据类型、连接设备、寄存器、读写属性、量程、工程单位、报警限值
- **设备配置**：PLC 品牌/型号、协议（Modbus TCP/RTU、MC、FINS…）、IP/端口、站号、波特率、超时与重试
- **Modbus ↔ PLC 映射表**：保持寄存器 ↔ D 区 / M 区，标注偏移基准
- **命令语言**：启停互锁、故障报警、运行计时、班次统计、弹窗提示
- **画面组态清单**：每个画面放哪些元件、动画连接方式、权限
- **报警与趋势配置清单**
- **离线仿真验证方案**

## 三、变量点表样例（AI 输出格式示范）

场景：三菱 FX5U + Modbus TCP，电机启停 + 故障报警 + 运行计时

| 变量名 | 类型 | 数据类型 | 连接设备 | 寄存器 | 读写 | 量程 | 说明 |
|---|---|---|---|---|---|---|---|
| 电机启动 | 内存 | 离散 | — | — | 读写 | 0/1 | 画面按钮按下量 |
| 电机运行 | I/O | 离散 | FX5U_ModbusTCP | Y0（线圈 1） | 读写 | 0/1 | PLC 输出 |
| 电机故障 | I/O | 离散 | FX5U_ModbusTCP | M10（线圈 11） | 只读 | 0/1 | 故障标志 |
| 运行秒数 | 内存 | 整型 | — | — | 读写 | 0~999999 | 累计运行秒 |
| 故障代码 | I/O | 整型 | FX5U_ModbusTCP | D100（保持 40101） | 只读 | 0~65535 | 低字节=故障码 |

> ⚠️ 寄存器列是**示意**，**本例默认假设 `D0 ↔ 40001`（1 基）**，即 `D100 = 40101`。
> 但这**不是通用真理**：Modbus 协议地址是 0 基（0x0000 起），人读编号才是 1 基（40001 起）；
> 而 `D100` 是否等于寄存器 100，**完全取决于该 PLC 的 Modbus 映射表**。
> 以三菱 FX5U 为例，其"软元件 Modbus 地址"参数决定了 D 区起始偏移，**默认并不等于 D0=40001**。
> **这一步必须按你所用 PLC 的 Modbus 映射手册人工核对，切勿照抄本例的 40101。**

## 四、命令语言样例

### 4.1 数据改变命令语言（变量"电机启动"变化时执行）

```
IF \本站\电机启动 == 1 THEN
    \本站\电机运行 = 1;
    // 启动时清零故障提示
    \本站\故障代码 = 0;
ELSE
    \本站\电机运行 = 0;
ENDIF
```

### 4.2 定时命令语言（1000ms 周期，做运行计时与心跳）

```
// 运行计时：电机运行时每秒 +1
IF \本站\电机运行 == 1 THEN
    \本站\运行秒数 = \本站\运行秒数 + 1;
ENDIF

// 心跳灯：用系统变量 $Second 的奇偶翻转（取模用 %，类 C 语法更通用）
IF ($Second % 2) == 0 THEN
    \本站\心跳灯 = 1;
ELSE
    \本站\心跳灯 = 0;
ENDIF
```

### 4.3 事件命令语言（故障时弹窗并记录）

```
IF \本站\电机故障 == 1 THEN
    ShowPicture("故障报警画面");
    // 记录时间戳字符串（按实际变量结构调整）
    \本站\故障时间 = $Year + "-" + $Month + "-" + $Day + " " + $Hour + ":" + $Minute + ":" + $Second;
ENDIF
```

> ⚠️ `ShowPicture`、取模（已改用 `%`，比 `mod()` 在类 C 命令语言里更通用）、字符串连接（`+` 或 `StrCat` 各版本不同）等语法随版本可能不同；若报错，查你版本的"命令语言函数手册"。
> ⚠️ `$Second` 等系统变量名以手册为准。

## 五、画面 / 报警组态清单

**画面清单**
1. `主画面`：电机示意图（启停动画）、启动/停止按钮、运行状态灯、运行时长显示、导航按钮
2. `参数设置画面`：频率/压力设定输入框（带写入权限与范围校验）
3. `故障报警画面`：当前报警列表（时间/变量/值/确认按钮）、历史报警查询
4. `趋势画面`：实时曲线 + 历史曲线，Y 轴量程与颜色区分

**动画连接要点**
- 按钮 → 命令语言（按下"电机启动"置 1，弹起置 0）
- 填充颜色 → 变量值域变化（运行=绿、故障=红、停机=灰）
- 数值显示 → 关联变量，设置小数位与工程单位
- 权限：参数写入画面设操作权限，防止误改

**报警配置要点**
- 每个报警变量设：限值、死区、优先级、是否需确认、是否记历史
- 故障类报警设"停机联锁"提示，但**不要**把组态里的停止当唯一保护手段

3) 命令语言：启停互锁、故障弹窗、运行计时（每秒+1）

## 七、红线

- **寄存器偏移必须按手册核对**（0 基 / 1 基、40001 与 D0 的关系）。
- 命令语言里的写入操作加**范围与合法性校验**。
- 组态软件可做**离线模拟运行**：先模拟验证逻辑，再连真机。
- 版本差异大，脚本先在低风险画面试跑。
