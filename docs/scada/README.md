# 组态软件 TOP5 —— AI 自动编程能力总览

本目录让本地助手针对**国内使用率最高的 5 个组态软件**具备"自动编程/自动组态起草"能力：
你给出品牌、PLC 型号、通信方式、控制需求，它就能产出**变量点表、设备配置、脚本、画面组态清单**等全套工件，你照着填进软件即可。

> 通用概念（变量/设备驱动/画面/报警/脚本）见 `docs/plc/hmi_scada_host.md`，本目录是**分品牌的深度能力**。
> 所有产出仅供起草，须工程师审核并在**离线/仿真环境**验证后才可上线（见 `docs/plc/SAFETY.md`）。

## 三、通用工作流（所有品牌一致）

1. **说清楚 5 件事**：品牌与版本 → 下位机（PLC/仪表型号）→ 通信方式（协议/IP/站号）→ 控制需求（启停、联锁、报警、曲线）→ 使用场景（触摸屏/PC/无人值守）。
2. **让 AI 先出点表和映射**，你核对寄存器地址（**这是最容易错的一步**）。
3. **再出脚本与画面清单**，你照着组态。
4. **离线仿真**：组态王/MCGS/WinCC/力控均可在 PC 上不带真机模拟运行；先用模拟验证逻辑再接设备。
5. **上线前按 `docs/plc/commissioning.md` 第五节点表逐项核对。**

4) 画面组态清单。所有地址标注 Modbus 寄存器号，并说明与 PLC 内部继电器的对应关系。

## 五、硬红线

- **地址映射必须人工核对**：AI 可能把 Modbus 40001 与 PLC D0 的偏移关系搞错（0 基/1 基、不同品牌换算不同）。
- **软件急停不能替代硬接线急停**；上位机/组态里的"停止"只是软件指令。
- **写入类操作必须加边界校验与确认**（尤其是频率、压力设定值）。
- **上线前离线仿真**，不要第一次就在真机上试。
- 各品牌脚本语法随版本变化，本目录样例均标注 ⚠️，**以你所用版本官方手册为准**。
