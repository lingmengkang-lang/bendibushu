# 昆仑通态 MCGS —— AI 自动编程能力

> MCGS 分**嵌入版**（跑在昆仑通态触摸屏，装机量极大）和**通用版**（跑在 PC）。
> 两者组态思路一致，本文件通用。⚠️ 脚本函数随版本（7.7 / 8.x）变化，以你所用版本手册为准。

## 一、核心概念速查

| 概念 | 说明 |
|---|---|
| **实时数据库** | 所有变量的家；变量分"设备通道"（绑寄存器）与"用户变量"（内部） |
| **设备窗口** | 挂 PLC/仪表驱动，配"设备构件"与"通道" |
| **用户窗口** | 画面，放图元/控件/动画 |
| **主控窗口** | 菜单、整体框架 |
| **运行策略** | 循环策略、报警策略、用户策略、事件策略、热键策略 |
| **脚本程序** | 类 C 语言，写在"策略块"里，按条件/周期执行 |

## 二、AI 能自动产出什么

- **实时数据库变量点表**：变量名、类型、初值、通道绑定、量程、报警属性
- **设备窗口配置**：父设备/子设备、通信协议与参数
- **脚本程序**：读写设备、启停联锁、故障弹窗、数据计算与累计
- **画面组态清单**：元件、动画连接、权限
- **报警与曲线配置**：报警限值、上下限、历史曲线变量
- **离线模拟验证方案**（嵌入版可用 PC 端模拟运行）

## 三、变量点表样例（AI 输出格式示范）

场景：嵌入版 MCGS + 西门子 S7-200 Smart，Modbus TCP，3 台变频器监控

| 变量名 | 变量类型 | 数据类型 | 通道/寄存器 | 读写 | 量程 | 说明 |
|---|---|---|---|---|---|---|
| 1号频率给定 | 设备通道 | 浮点 | VW100（保持寄存器） | 读写 | 0~50.0 Hz | 写设定频率 |
| 1号输出频率 | 设备通道 | 浮点 | VW102 | 只读 | 0~50.0 Hz | 变频器反馈 |
| 1号故障码 | 设备通道 | 整型 | VW104 | 只读 | 0~65535 | 故障代码 |
| 累计电量 | 用户变量 | 浮点 | — | 读写 | 0~99999 | 脚本累加 |
| 系统时间秒 | 用户变量 | 整型 | — | 只读 | 0~59 | 取系统时钟 |

> ⚠️ 寄存器为**示意**。S7-200 Smart 的 Modbus 映射需按西门子手册确认。
> MCGS 的"设备通道"地址还要在设备构件属性里做一次映射，两处都要核对。

## 四、脚本程序样例（类 C）

### 4.1 循环策略块（约 200ms 执行一次）

```c
/* 变频器故障弹窗：任一故障码非 0 时弹提示 */
if (1号故障码 != 0 || 2号故障码 != 0 || 3号故障码 != 0) {
    !SetWindow("故障提示窗口", 1);   /* ⚠️ 函数名随版本，可能是 !OpenWindow 等 */
    系统状态 = 2;
} else {
    系统状态 = 1;
}

/* 运行状态累计：频率 > 0.5Hz 视为运行，每周期累加电量 */
if (1号输出频率 > 0.5) {
    累计电量 = 累计电量 + 1号输出电流 * 0.2 / 3600.0;
}
```

### 4.2 用户策略块（点击"启动"按钮触发）

```c
/* 写频率给定，带范围校验（防呆） */
if (设定频率 < 0)   设定频率 = 0;
if (设定频率 > 50)  设定频率 = 50;

/* 写入设备：函数名与参数形式随版本变化 */
!SetDevice(0, "Write", "1号频率给定", 设定频率);   /* ⚠️ 示意 */
```

> ⚠️ MCGS 内置函数多为 `!` 开头（如 `!SetWindow` / `!SetDevice` / `!Sleep` / `!Beep`），
> **具体名称、参数个数与顺序各版本不一致**，务必在"脚本程序函数手册"里核对后再用。
> 纯变量赋值与 `if/while/for` 逻辑是稳定的，可放心用。

## 五、画面 / 报警组态清单

**画面清单**
1. `主监控画面`：3 台变频器卡片（频率/电流/状态灯）、总启停按钮
2. `参数设置画面`：各台频率给定输入框（权限控制）
3. `故障记录画面`：报警列表 + 确认按钮 + 历史查询
4. `曲线画面`：实时/历史曲线，勾选要看的变量

**动画连接要点**
- 按钮 → 执行用户策略块
- 填充/闪烁 → 变量值域（运行绿、故障红闪烁、停止灰）
- 输入框 → 关联用户变量，设上下限
- 多语言/权限：按操作员/工程师分级

**报警配置要点**
- 每个监控变量设上下限、死区、优先级
- 故障类设"触发时打开指定窗口"
- 报警数据落盘，便于事后追溯

## 七、红线

- **两处地址都要核对**：设备构件属性 + 实时数据库通道。
- 写入类函数参数不确定时，先在仿真环境试，别直接连真机。
- 嵌入版注意**存储空间与刷新周期**，别把循环策略设得过密。
- 报警弹窗别做成"必须点掉才能继续"，避免遮挡关键信息。
