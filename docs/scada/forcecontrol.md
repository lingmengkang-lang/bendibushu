# 力控 ForceControl —— AI 自动编程能力

> 北京三维力控，国产 SCADA 第二梯队领头，石化、市政、能源项目常见。
> 常见版本：**ForceControl V7.x**、**pSpace**（企业级实时数据库）。
> ⚠️ 脚本语法随版本变化，以你所用版本手册为准。

## 一、核心概念速查

| 概念 | 说明 |
|---|---|
| **实时数据库（DB）** | 核心，所有参数/变量集中管理，分"系统点/设备点/中间点/计算点" |
| **数据库变量** | 点参数（PINA 等）描述量程、报警、历史存盘属性 |
| **设备驱动** | 在"I/O 驱动"里配，支持串口/以太网/OPC 等 |
| **画面** | 开发系统里做，图元 + 动画连接 + 脚本 |
| **脚本** | 类 Basic / 类 C 混合（版本间有差异），用于事件与逻辑 |
| **报警 / 历史** | 报警配置 + 历史库（趋势、报表） |
| **组件 / 控件** | 趋势、报警、报表、配方等现成控件 |

## 二、AI 能自动产出什么

- **实时数据库点表**：点号/点名、点类型、设备与通道、量程、单位、报警限值、是否存历史
- **I/O 驱动配置清单**：设备、协议、通道、波特率/IP、寄存器映射
- **脚本**：启停联锁、故障判断、数据计算与累计、画面联动
- **画面组态清单**：图元、动画、权限
- **报警与历史趋势配置清单**
- **离线运行验证方案**（力控支持不带真机的模拟运行）

## 三、实时数据库点表样例（AI 输出格式示范）

场景：汇川 AM400 变频器 + Modbus TCP，空压机监控

| 点号 | 点名 | 点类型 | 通道/寄存器 | 量程 | 单位 | 报警 | 存历史 |
|---|---|---|---|---|---|---|---|
| AI01 | 排气压力 | 模拟量 | 保持 40100 | 0~1.6 | MPa | 高 1.4 / 低 0.3 | 是 |
| AI02 | 机头温度 | 模拟量 | 保持 40101 | 0~150 | ℃ | 高 105 | 是 |
| DI01 | 运行状态 | 开关量 | 线圈 1 | 0/1 | — | 变位报警 | 否 |
| DI02 | 故障报警 | 开关量 | 线圈 2 | 0/1 | — | 变位报警 | 是 |
| AO01 | 压力设定 | 模拟量 | 保持 40200 | 0~1.6 | MPa | — | 否 |
| CA01 | 累计电量 | 计算量 | — | 0~99999 | kWh | — | 是 |

> ⚠️ 寄存器为**示意**，AM400 的 Modbus 地址需按汇川手册确认。

## 四、脚本样例

### 4.1 压力超限处理（事件/条件脚本）

```basic
' ⚠️ 力控脚本各版本写法有差异（类 Basic / 类 C），以下为逻辑示意
IF DI02 == 1 THEN
    ' 故障：停机命令 + 记录时间
    AO01 = 0
    ShowWindow("故障报警窗口")
ELSE
    IF AI01 > 1.4 THEN
        ' 压力高限：先卸荷再报警
        高压报警 = 1
    ELSE
        高压报警 = 0
    END IF
END IF
```

### 4.2 累计电量计算（定时脚本，1s 周期）

```basic
' 简化：按电流估算电量（实际应按功率积分）
IF DI01 == 1 THEN
    CA01 = CA01 + AI03 / 3600.0
END IF
```

> ⚠️ 力控脚本的变量引用方式（直接点名 / `#点名` / 函数取值）随版本与配置不同，
> **先在测试画面里验证变量读写通不通，再写复杂逻辑**。

## 五、画面 / 报警 / 趋势配置清单

**画面清单**
1. `空压机总览`：压力/温度/状态灯、启停按钮、设定值显示
2. `参数设置`：压力上下限、加载/卸载压力（权限控制）
3. `报警画面`：实时报警 + 历史报警查询
4. `趋势画面`：压力/温度/电量实时 + 历史曲线
5. `报表画面`：班次报表、电耗日报

**报警配置要点**
- 模拟量上下限 + 死区 + 报警级别
- 开关量变位报警（运行状态跳变要留痕）
- 报警分级：停机类 / 预警类 / 提示类

**历史与报表要点**
- 存历史前先设好"存盘周期"，别默认过快写满磁盘
- 报表变量要与历史库变量对上

## 七、红线

- 点表里"通道/寄存器"与设备实际地址必须一致，**这是力控现场最高频的坑**。
- 计算点（如电量累计）注意掉电清零问题，重要数据放 PLC 或做掉电保持。
- 存盘周期要按磁盘容量估算。
- 压力/温度等安全相关保护，**最终由 PLC/硬件回路兜底**，不要只靠 SCADA 脚本。
