# 威纶通 WEINVIEW EBPro —— AI 自动编程能力

> EBPro（EasyBuilder Pro）是威纶通触摸屏组态软件，**免费下载、跨品牌兼容好**，
> HMI 组态装机量极大（现场 "WEINVIEW 屏" 随处可见）。
> ⚠️ 宏函数随 EBPro 版本（V6.x）变化，以你所用版本手册为准。

## 一、核心概念速查

| 概念 | 说明 |
|---|---|
| **元件** | 按钮、指示灯、数值显示、输入、图表、报警等 |
| **地址** | 元件绑定的设备地址（如 `4x` 保持寄存器、`0x` 线圈、`3x` 输入寄存器） |
| **设备** | 新增 PLC/仪表驱动，配通信参数（串口/以太网） |
| **宏（Macro）** | 脚本语言，类似 C 与 Basic 混合，用于复杂逻辑 |
| **事件登录 / 报警** | 事件与报警记录、报警条 |
| **资料取样（Data Sampling）** | 历史数据采样，喂趋势图 |
| **排程（Scheduler）** | 定时动作 |

## 二、AI 能自动产出什么

- **元件地址表**：每个元件的地址、类型（读/写）、格式（位数/小数/单位）
- **设备配置清单**：PLC 品牌型号、协议、IP/端口、站号
- **Modbus 地址换算**：EBPro 的 `4x/3x/0x/1x` 与 PLC 内部区（D/M/Y）的对应
- **宏程序**：参数写入校验、权限切换、弹窗、计算
- **画面组态清单**：窗口结构、元件、动画
- **报警 / 取样 / 排程配置清单**
- **离线模拟验证方案**（EBPro 支持 Off-line / On-line 模拟）

## 三、元件地址表样例（AI 输出格式示范）

场景：台达 DVP-12SE + Modbus RTU，单机调试 HMI

| 窗口 | 元件 | 地址 | 类型 | 格式 | 说明 |
|---|---|---|---|---|---|
| 主窗口 | 启停按钮 | `0x0001` | 位，置 ON/OFF | — | 瞬动，走宏做互锁 |
| 主窗口 | 运行指示灯 | `0x0002` | 位，只读 | — | 绿=运行 |
| 主窗口 | 故障指示灯 | `0x0003` | 位，只读 | — | 红闪=故障 |
| 主窗口 | 频率给定输入 | `4x0001` | 字，读写 | 16 位无符号，1 位小数 | 0~50.0 Hz |
| 主窗口 | 输出频率显示 | `4x0002` | 字，只读 | 同上 | 变频器反馈 |
| 主窗口 | 故障码显示 | `4x0003` | 字，只读 | 16 位无符号 | 需查手册释义 |

> ⚠️ 台达 DVP 的 Modbus 映射需按台达手册确认（D 区 ↔ 保持寄存器的偏移、`0x/4x` 与 Y/M/D 的对应）。
> ⚠️ EBPro 里 `4x` 通常表示保持寄存器（4xxxx），实际通信地址还要减 1 或按设备定义，**务必实测**。

## 四、宏程序样例

### 4.1 启动按钮宏（互锁 + 防呆）

```c
// ⚠️ EBPro 宏语法随版本变化，以下为逻辑示意
short fault;

// 读故障位（函数名与参数形式按版本手册核对）
fault = GetData(0x0003, 1);   // ⚠️ GetData 参数形式各版本不同

if (fault == 1) {
    // 故障中禁止启动，弹提示窗口
    SetData(0x0010, 1);       // ⚠️ 设置提示标志
    return;                    // 直接返回，不下发启动
}

// 无故障才允许启动
SetData(0x0001, 1);
```

### 4.2 频率给定写入校验

```c
// 限制设定范围 0~500（对应 0~50.0Hz，1 位小数）
long setval;

setval = GetData(0x0011, 1);
if (setval > 500) setval = 500;
if (setval < 0)   setval = 0;
SetData(0x0011, setval);
```

> ⚠️ EBPro 宏的 `GetData` / `SetData` 各版本参数格式（是否带数据类型、返回值）有差异，
> **先在测试窗口里跑通一个读写再扩展**。

## 五、画面 / 报警 / 取样配置清单

**窗口结构**
1. `主窗口`：运行状态、频率给定/显示、启停按钮、报警条、导航
2. `参数窗口`：限值设置（权限）、加减速时间
3. `报警窗口`：事件/报警列表、确认
4. `趋势窗口`：资料取样曲线
5. `系统窗口`：时间、权限登录、语言切换

**动画与权限要点**
- 元件"监视"地址设只读，"写入"地址设可改
- 权限：操作员可调设定，工程师可改参数，管理员可改配方
- 数值输入元件设上下限，防止误输超范围值

**资料取样与排程要点**
- 取样变量选关键量（频率/电流/故障码），采样周期别太密（屏存储有限）
- 排程做"每天清零累计""定时记录"

## 七、红线

- **`4x/3x/0x/1x` 偏移基准必须实测**，这是 EBPro 现场最高频的坑（差 1 就全偏）。
- 宏里写设备前先校验，避免误写参数导致设备动作异常。
- 屏的存储与刷新有限，采样周期与报警条数量要克制。
- 触摸屏上的"停止"只是通信指令，**急停必须硬接线**。
